# 🏔️ Zero-Docker Alpine Homelab Appliance (Bare-Metal + LXC Sandbox)

> **Модульный программный комплекс для домашнего сервера и умного шлюза на базе Alpine Linux (2026).**  
> Никакого Docker. Никакого systemd. Все основные службы работают нативно под OpenRC с рекордно низким потреблением памяти (~440 МБ RAM), а встроенная подсистема **LXC Sandbox** предоставляет полигон для любых контейнеров с получением IP от домашнего роутера и снимками состояний.

---

## 🌟 Ключевые преимущества

- **Минимальный оверхед**: Вся система (11 служб, включая веб-панели, торренты, медиасервер, Git, прокси-шлюз и LXC) потребляет всего **~440 МБ RAM**.
- **Чистый Zero-Docker стек**: Все службы хоста управляются нативным демоном **OpenRC** с `supervise-daemon` и защищены непривилегированными системными аккаунтами.
- **Модульная архитектура 2026**: Проект разбит на независимые компоненты (`core/`, `services/`), легко обновляется и дополняется.
- **Единый CLI-оркестратор (`homelab`)**: Управление комплексом, диагностика системы (`homelab doctor`), обновление (`homelab update`), статус и логи.
- **Зеленый HTTPS из коробки**: Встроенный **Caddy 2 Local PKI** автоматически генерирует доверенные сертификаты для всех локальных доменов `*.lan` без предупреждений безопасности в браузере.
- **Прозрачный умный шлюз (Smart Gateway)**: Ядро **sing-box-extended 1.14.3** с TUN-интерфейсом и панелью **Metacubexd** направляет заблокированный трафик через прокси, пропуская российский сегмент напрямую без потери скорости.
- **Централизованный DNS & Ad-blocking**: **sing-box** на порту 53 обеспечивает бинарную фильтрацию рекламы (AdGuard DNS filter `.srs`), локальный резолв `*.lan` на Caddy и раздельный DoT/DoH-резолв.
- **Встроенная песочница LXC Sandbox**: Запуск любых дистрибутивов (Alpine, Debian, Ubuntu, Arch, Fedora, Rocky), прямое получение IP от роутера (LAN DHCP), мгновенные снимки (`lxc-snapshot`) и Web Terminal (`ttyd`).

## 🚀 Быстрый старт (Доставка и запуск в одну команду)

### Вариант 1: Прямой Git Clone (Рекомендуется)
На чистой установленной Alpine Linux выполните:
```bash
apk add --no-cache git curl && git clone https://github.com/unknownpeace/alpine-homelab.git /opt/homelab && cd /opt/homelab && ./homelab.sh install
```

### Вариант 2: One-Liner Bootstrap
```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/unknownpeace/alpine-homelab/master/bootstrap.sh)"
```

Установщик автоматически:
1. Настроит системные репозитории и пакеты.
2. Включит ускорение сети TCP BBR и маршрутизацию.
3. Атомарно создаст сетевые мосты `br0` (для роутерного DHCP) и `lxcbr0` (NAT-песочница) без потери SSH-соединения.
4. Развернет sing-box, Caddy 2, медиа-сервисы и веб-менеджер LXC.
5. Создаст глобальную команду `homelab` в `/usr/local/bin/homelab`.

## 🛠️ Управление комплексом (`homelab` CLI)

После установки на сервере доступна единая утилита администрирования:

- **Диагностика системы («Доктор»):**
  ```bash
  homelab doctor
  ```
  Проверяет статус всех 11 служб OpenRC, сетевые мосты, DNS sing-box (`*.lan`), доступность HTTPS-доменов и ресурсы.
- **Обновление системы и правил:**
  ```bash
  homelab update
  ```
  Подтягивает свежие изменения из Git, обновляет базы антиблокировок sing-box и перезапускает сервисы.
- **Статус комплекса:**
  ```bash
  homelab status
  ```
- **Управление отдельной службой:**
  ```bash
  homelab service restart sing-box
  homelab service status lxc-manager
  homelab service logs caddy
  ```

### 📦 Встроенная песочница LXC Sandbox (`https://lxc.lan`)

В Bare-Metal редакции встроен полноценный веб-менеджер контейнеров:
- **Официальный каталог дистрибутивов (`images.linuxcontainers.org`)**: выбор дистрибутива и релиза без костылей — Alpine (3.24, 3.23, edge), Debian (12 Bookworm, 13 Trixie, sid), Ubuntu (24.04 LTS, 22.04 LTS), Arch Linux, Fedora (41, 40), Rocky Linux (9, 8), AlmaLinux. Кэширование образов ускоряет повторное развертывание до 1-2 сек.
- **Два режима сети на выбор**:
  - **Домашняя сеть LAN (`br0`)**: контейнер подключается напрямую к сетевому мосту хоста и получает персональный IP-адрес от домашнего роутера по DHCP (`192.168.1.x`). Контейнер доступен как отдельное физическое устройство в домашней сети.
  - **Изолированная песочница (`lxcbr0`, `10.0.3.0/24`)**: приватный NAT-сегмент с маскарадингом в `nftables`, хостовым DNS sing-box и фильтрацией рекламы.
- **Снимки и быстрый откат (Snapshots & Rollback)**: создание мгновенных именованных слепков контейнеров (`lxc-snapshot` на базе `rsync`), просмотр списка снимков, откат контейнера к любому сохраненному состоянию за секунду и удаление устаревших снимков прямо из UI.
- **Интерактивный Web Terminal (`ttyd`)**: полноценная эмуляция ANSI xterm.js терминала в окне браузера через WebSocket с поддержкой цветов, горячих клавиш, копирования/вставки и прямого шелла (`lxc-attach`).
- **Быстрый запуск команд (Web Exec)**: моментальное выполнение команд без интерактивного терминала с выводом времени выполнения и кода завершения.
- **Управление жизненным циклом**: Старт, Стоп, Перезапуск, Заморозка (`lxc-freeze`), Удаление с очисткой снимков, Автозапуск (`lxc.start.auto`).
- **Сверхлегкий движок**: бэкенд на Python 3 + `py3-bottle` (~12 МБ RAM) и C-демон `ttyd` (~1.8 МБ RAM) управляются OpenRC `supervise-daemon`.

## 📱 Настройка клиентских устройств (ПК, Смартфоны)

### 1. Настройка DNS и Шлюза
В свойствах сетевого адаптера устройства (Wi-Fi или Ethernet):
- **DNS-сервер**: укажите `192.168.1.140` (sing-box DNS & AdBlock). После этого все адреса `*.lan` будут открываться мгновенно, а реклама блокироваться.
- **Основной шлюз (Gateway)** *(опционально)*: укажите `192.168.1.140` (proxybox), если хотите пустить весь трафик устройства через умный туннель sing-box.

### 2. Установка корневого сертификата (Зеленый HTTPS)
Чтобы браузеры не показывали предупреждение о самоподписанном сертификате:
1. Скачайте файл `/root/caddy-homelab-root.crt` с хоста на ваш компьютер.
2. В Windows:
   - Дважды кликните по файлу `.crt` -> **Установить сертификат**.
   - Выберите **Текущий пользователь** -> **Поместить все сертификаты в следующее хранилище**.
   - Нажмите **Обзор** и выберите **«Доверенные корневые центры сертификации»** (Trusted Root Certification Authorities).
   - Подтвердите установку. Все сайты `*.lan` станут доверенными с валидным замком HTTPS.

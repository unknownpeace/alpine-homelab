# Модель безопасности и харднинг (Zero-Docker Alpine Homelab)

1. **Unified Cgroups v2 & LXC**: Ограничение прямого доступа к устройствам ядра. Доступ к `/dev/net/tun` выдан строго контейнеру `proxybox`.
2. **Непривилегированные демоны**: Ни один сервис не работает под root. Vaultwarden, Forgejo, Conduit, Transmission и Navidrome запускаются под собственными системными пользователями.
3. **Bcrypt HTTP Basic Auth**: Сервисы управления защищены на уровне Caddy с Bcrypt-хешированием.
4. **Local PKI**: Caddy изолирован с директивой `install_trust false`, исключая попытки несанкционированной перезаписи системного хранилища сертификатов хоста.
5. **Nftables NAT**: Изолированная таблица NAT в `proxybox` с маскарадингом через `tun0`.

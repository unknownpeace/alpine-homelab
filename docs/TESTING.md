# Журнал тестирования и QA-отладка (VirtualBox Regression Matrix)

В рамках разработки и доводки скрипта развертывания проведено непрерывное регрессионное тестирование на виртуальной машине Oracle VirtualBox с дистрибутивом **Alpine Linux 3.24**.

Методология строится на циклических прогонах:
`Откат снимка ОС -> Передача скрипта -> Автономная установка -> Глубокий аудит логов -> Исправление кода -> Коммит -> Повтор`.

---

## Хронология циклов тестирования и устраненных дефектов

### Цикл 1: Несовместимость шаблонов LXC 7.0 в Alpine 3.24
- **Симптом:** `lxc-create: get_template_path: 1012 No such file or directory - bad template: download`.
- **Решение:** Внедрен **Golden Rootfs Cache** (`/var/cache/lxc/alpine-rootfs.tar.gz`). Время сборки контейнера снизилось с 40 секунд до 0.2 секунды.

### Цикл 2: Сетевой мост и прерывание SSH
- **Симптом:** Потеря связи при ручном создании моста.
- **Решение:** Добавлен блок атомарной миграции `eth0 -> br0` без разрыва активной SSH-сессии.

### Цикл 3: Троттлинг GitHub CDN в РФ и устаревший синтаксис sing-box 1.14
- **Симптом:** Зависание загрузки Metacubexd с `codeload.github.com` (25 КБ/с), ошибки синтаксиса DNS и парсинга `idle_only` в sing-box.
- **Решение:** Переход на релизный CDN-архив Metacubexd (1 секунда). Миграция DNS на типизированные объекты 1.14, удаление `idle_only`, перенос перехвата трафика в `route.rules`.

### Цикл 4: Права портов Vaultwarden, Conduit DB и Wildcard DNS
- **Симптом:** Permission denied на порту 443 под unprivileged-юзером, краш Conduit без `database_path`, NXDOMAIN в AdGuard.
- **Решение:** Перенос Vaultwarden на внутренний порт 8000 через Caddy, явная директива `database_path`, правила `|*.lan^$dnsrewrite=192.168.1.51`.

### Цикл 5: Синтаксис скрипта установки
- **Симптом:** Ошибка на строке 921 `EOF: not found` (код 127).
- **Решение:** Удален фантомный токен, зафиксирован чистый возврат `exit 0`.

### Цикл 6: Внедрение тестового раннера CI/CD
- **Решение:** Разработан скрипт `tests/test_e2e_vm.py` для автоматического сброса VirtualBox и верификации всех 8 сервисов.

### Цикл 7: Полный аудит логов и оптимизация под реалии РФ 2026
- **Симптом 1:** В логах Transmission непрерывно спамилось `State changed from 'Starting' to 'Not forwarded'` каждые 8 секунд из-за неудачного UPnP в NAT-бридже.
  - *Решение:* Отключен UPnP через `"port-forwarding-enabled": false` в `settings.json`.
- **Симптом 2:** В веб-интерфейсе Forgejo ссылки на клонирование репозиториев вели на `http://localhost:3000/`.
  - *Решение:* В `/etc/forgejo/app.ini` зафиксирован `ROOT_URL = https://git.lan/`.
- **Симптом 3:** В Vaultwarden отсутствовала переменная `DOMAIN`, блокируя работу WebAuthn / Passkeys / FIDO2 в браузерах.
  - *Решение:* Добавлен `DOMAIN=https://vault.lan` в `.env`.
- **Симптом 4:** При переходе на `https://proxy.lan/` отображался сырой JSON Clash API (`{"hello":"clash"}`), а для Transmission требовалось вводить длинный URL `/transmission/web/`.
  - *Решение:* В Caddyfile добавлены автоматические редиректы `redir / /ui/` и `redir / /transmission/web/`.
- **Симптом 5:** В AdGuard Home использовались незашифрованные DNS-серверы, уязвимые к ТСПУ, отсутствовал фильтр рекламы для Рунета.
  - *Решение:* Добавлены DoH-апстримы (Яндекс, Cloudflare), включен AdGuard Russian filter (ID 7), активирован `cache_optimistic` и отключен AAAA.
- **Симптом 6:** Сетевой стек Linux работал на классическом Cubic с планировщиком pfifo_fast.
  - *Решение:* Активирован алгоритм **Google BBR** и планировщик `fq` через `modprobe tcp_bbr` и `sysctl`.

### Цикл 8: Нативные бинарные rule-sets (.srs) в sing-box 1.14 и очистка подписки
- **Симптом 1:** В sing-box вместо полноценных баз GeoIP/GeoSite использовался ограниченный список суффиксов `domain_suffix: ru_domains`, не покрывавший тысячи российских подсетей и сервисов.
  - *Решение:* Подключены скомпилированные бинарные rule-sets RunetFreedom (`geoip-ru.srs`, `geosite-tld-ru.srs`, `geosite-category-ru.srs`, `geosite-ru-blocked.srs`), загружаемые с jsDelivr/GitHub CDN с локальным сохранением в `/var/lib/sing-box/rules/`.
- **Симптом 2:** Провайдерские информационные заглушки (`ℹ️ Срок`, `⛔️ Торренты`, `127.0.0.1:1`) забивали UI и ломали селекторы.
  - *Решение:* Добавлен фильтр dummy-нод в `update-sub.py`.
- **Симптом 3:** Группа `🌐 Автовыбор` в исходной подписке провайдера содержала только 3 узла.
  - *Решение:* Пересобрана группа `urltest` с динамическим включением всех 205+ рабочих серверов.
- **Симптом 4:** Параметр `strict_route: true` на TUN-интерфейсе в multi-homed окружении контейнера вызывал риск сетевых коллизий.
  - *Решение:* Установлен `strict_route: false`, `log.level: info`, `default_domain_resolver: direct-dns`.
- **Итог:** Успешный сквозной прогон с чистого снимка ОС. Точность классификации подтверждена тестами `sing-box rule-set match -f binary` (youtube.com -> blocked, ya.ru -> tld-ru, vk.com -> category-ru, 77.88.8.8 -> geoip-ru). Потребление памяти системы — **491.9 МБ RAM**.

### Цикл 9: Выделенная группа `🤖 Нейросети` и интеграция MetaCubeX AI-правил
- **Потребность:** Жёсткий антифрод Claude/ChatGPT/Gemini и капчи Cloudflare требовали возможности направить трафик нейросетей через чистый/специфический узел независимо от общего трафика.
- **Решение:**
  - Интегрирована официальная бинарная база `geosite-category-ai.srs` (MetaCubeX `category-ai-!cn`).
  - В sing-box добавлен выделенный селектор `🤖 Нейросети` и изолированный DoT апстрим `ai-dns` (1.1.1.1:853 с `detour: "🤖 Нейросети"`).
  - Маршруты AI получили приоритетный перехват перед общим списком блокировок.
- **Итог:** Автоматический сквозной прогон с чистого снимка подтвердил корректность матчинга `chatgpt.com`, `claude.ai` и `gemini.google.com`. Потребление памяти системы — **488.9 МБ RAM**.

### Цикл 10: Интерактивный мастер выбора прокси и всеядный парсер протоколов
- **Потребность:** Необходимость ввода пользователем собственной подписки или одиночной ссылки на сервер (VLESS Reality, Shadowsocks, Trojan, Hysteria 2) прямо при установке, с сохранением автономности unattended-установки в CI.
- **Решение:**
  - В начало `install-homelab.sh` внедрён интерактивный CLI-диалог с 4 опциями и тайм-аутом 30 сек (`read -t 30`).
  - В `update-sub.py` реализован чистый Python-парсер share-ссылок: `vless://` (с параметрами Reality, Vision, gRPC, WS), `ss://` (SIP002 Base64 и AEAD), `trojan://` (TLS/uTLS), `hysteria2://`/`hy2://` (Salamander обфускация).
  - Добавлена поддержка Base64-подписок и безопасный fallback в режим `direct` (без падений sing-box).
- **Итог:** Успешный прогон CI на чистом снимке ОС. Ручные тесты подтвердили генерацию валидных конфигураций sing-box 1.14 для одиночных ссылок VLESS Reality, Shadowsocks, Trojan и прямых подписок. Потребление RAM — **495.1 МБ**.
